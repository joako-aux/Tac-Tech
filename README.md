# Tac-Tech

Versión 2 de TacTech en migración: de Activities XML + SQLite a **Jetpack Compose + MVVM**,
con Room, Retrofit y un microservicio propio.

| Carpeta | Contenido |
|---|---|
| `tactech-backend/` | Microservicio Spring Boot + MySQL, desplegado en AWS EC2 |
| `TacTech/` | Aplicación Android (Kotlin + Jetpack Compose) |

La versión 1 (XML + SQLite) queda en el historial de commits anterior a esta migración.
